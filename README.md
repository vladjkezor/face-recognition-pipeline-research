# Face Recognition Pipeline

Этот репозиторий содержит реализацию полного пайплайна для распознавания лиц: от выравнивания лица по ключевым точкам до генерации эмбеддингов и сравнения лиц по косинусному расстоянию. Также реализована метрика **Identification Rate (TPR@FPR)** для оценки качества моделей.

- На части графиков не отобразил легенду: синяя линия - Train, оранжевая - Val

## 📁 Структура проекта

```
├── data/ # Картинки для тестирования пайплайна
│ └── celeba/ # Подмножество датасета CelebA
│     └── Anno/ # Аннотации
│         ├── identity_CelebA.txt
│         ├── list_bbox_celeba.txt
│         └── list_landmarks_celeba.txt
│
├── notebooks/ # Основные ноутбуки
│   ├── 1_FaceAlignment.ipynb # Обучение SHG и выравнивание лиц
│   ├── 2_FaceRecognition.ipynb # Обучение моделей и метрика IR
│   ├── 3_Pipeline.ipynb # Полный пайплайн: от картинки до эмбеддинга
│   └── models/ # Сохранённые модели и веса
│
├── src/
│   └── utils.py # Утилиты для загрузки данных и выравнивания

```

## 📚 Описание ноутбуков

### 1. `1_FaceAlignment.ipynb`

- Обучение **Stacked Hourglass Network (SHG)** для нахождения ключевых точек на лице
- Функция, которая принимает фотографию и возвращает выровненное лицо по ключевым точкам

### 2. `2_FaceRecognition.ipynb`

- Обучение моделей **ResNet18** и **ResNet50** с использованием:
  - Cross-Entropy Loss (CE)
  - ArcFace Loss
- Реализация метрики **Identification Rate (TPR@FPR)** для оценки качества распознавания на лицах вне обучающей выборки
- Сравнение обученных моделей по метрике

### 3. `3_Pipeline.ipynb`

- Полный пайплайн распознавания лиц:
  - Детекция лиц на изображении
  - Выравнивание
  - Получение эмбеддингов
  - Сравнение по косинусному расстоянию
- Примеры сравнения лиц одного и разных людей

### 4. `4_open_source_solutions.ipynb`

- Обзор 3-х open source библиотек для задачи face recognition
  - Описание
  - Установка
  - Тестирование

## 📦 Данные

- Используется датасет **CelebA**.
- Аннотации находятся в папке `data/celeba/Anno/`:
  - `identity_CelebA.txt` — ID для каждого изображения
  - `list_bbox_celeba.txt` — координаты bounding-box
  - `list_landmarks_celeba.txt` — ключевые точки лица
  - для первого ноутбука загрузка 10к картинок осуществляется через `src.utils.load_data()`
  - для загрузки всего датасета необходимо перейти по ссылке https://drive.google.com/drive/folders/0B7EVK8r0v71peklHb0pGdDl6R28?resourcekey=0-f5cwz-nTIQC3KsBn3wFn7A&usp=drive_link, скачать архив и распаковать его в папку data
